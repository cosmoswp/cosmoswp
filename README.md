# CosmosWP


**Fast, Dynamic & Elegant Free WordPress Theme for Any Website**


CosmosWP is a lightweight, multipurpose WordPress theme built for anyone who wants a beautiful, high-performing website without touching a single line of code. Whether you're building a business site, agency portfolio, blog, medical practice, education platform, fitness studio, or online store, CosmosWP gives you the tools to design it visually — with real-time customization and dozens of ready-made layouts to start from.


---


## Why CosmosWP


- **Blazing Fast** — loads in as little as 206ms on a default install, with a theme package under 1MB. Scores an A+ on GTmetrix, 100 on Google PageSpeed, and 99% on YSlow.
- **Free, Forever** — a full-featured free theme with no artificial limits on core design tools.
- **Code-Free Customization** — every design decision (colors, fonts, layouts, header, footer) is made visually through the WordPress Customizer. No coding knowledge required.
- **SEO Friendly** — clean, standards-based markup that's built to rank well out of the box.
- **Gutenberg & Page Builder Ready** — designed around the native block editor and fully compatible with Gutentor, Elementor, Beaver Builder, Divi, Visual Composer, and other major builders.
- **WooCommerce Ready** — a complete, conversion-focused toolkit for running an online store.
- **Mobile Optimized** — every layout and design option can be fine-tuned separately for desktop, tablet, and mobile.

## Drag-and-Drop Header & Footer Builder


Build a completely custom header and footer without templates locking you in.


**Header Builder**
- Three customizable rows — top, main, and bottom
- Drag-and-drop elements: logo/site identity, primary & secondary menus, search (dropdown or inline), buttons, social icons, contact information, custom HTML, and a widget area
- Choose from Normal, Overlay Fixed, Overlay Transparent, or Vertical header styles
- Custom menu icon and sidebar-style mobile menu


**Footer Builder**
- Three customizable rows — top, main, and bottom
- Up to 8 footer widget areas, plus copyright text, footer menu, social icons, and custom HTML
- Normal or Parallax footer styles

## Layout & Design Freedom


CosmosWP gives you fine control over how content is structured, site-wide or on a per-page basis:


| Category | Options |
|---|---|
| Site Layout | Full Width, Boxed, Fluid |
| Content Layout | Default, Content Boxed, Separate Boxed, Sidebar Boxed, and more |
| Sidebar Layout | No sidebar, left, right, or dual sidebars — set globally or per page/post |
| Header Position | Normal, Overlay Fixed, Overlay Transparent, Vertical |


On top of that, every element on the site — buttons, spacing, borders, box shadows, breadcrumbs, forms, comments, and search — has its own dedicated styling options.

## Getting Started


1. From your WordPress dashboard, go to **Appearance → Themes → Add New**, search for **CosmosWP**, then click **Install** and **Activate**.
   - Alternatively, download the theme from [cosmoswp.com](https://www.cosmoswp.com/) and upload it under **Appearance → Themes → Add New → Upload Theme**.
2. *(Optional but recommended)* Browse the [Starter Site Library](https://www.demo.cosmoswp.com/), pick a design close to what you need, and import it with one click.
3. Head to **Appearance → Customize** to adjust colors, typography, header, footer, and layouts — all changes preview live, and nothing requires code.
